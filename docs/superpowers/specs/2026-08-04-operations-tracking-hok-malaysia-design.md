# Aurora 後台、追蹤與 HOK 馬來西亞增長設計

## 目標

本輪工作先讓營運後台在資料服務失敗時仍然可理解、可重試，再把顧客來源及主要轉化事件記錄完整，最後建立馬來西亞優先的 HOK 多語言內容。任何未取得 Google 報表憑證的情況都必須清楚顯示「尚未連接」，不得製造流量數字。

## 已批准範圍

1. 修正營運管理載入失敗後永久停在空白／載入畫面的問題。
2. 保留既有價格、訂單、預約、人員與營業規則，不重寫已完成系統。
3. 客源追蹤增加 Carousell、Instagram、WhatsApp、LINE、Discord、Google、直接進入及其他來源；保存 `utm_content`，用來分辨商品、簡介或貼文。
4. 將完成報價與聯絡點擊視為重要轉化事件；不傳送顧客填寫內容、電話、聊天或付款資料給 Google。
5. 後台客源頁同時呈現站內查詢／訂單資料及 Google 報表連線狀態。Google 憑證缺失或失效時顯示設定指引及外部控制台連結。
6. HOK 表單增加具體國家，馬來西亞、新加坡、印度尼西亞、菲律賓、泰國及越南自動歸入東南亞大區；原有六大區仍作為中央伺服器資料。
7. 新增馬來西亞 HOK 的馬來文、英文、簡體中文三個可索引頁面，包含獨立網址、正確語言、互相對應的 `hreflang`、FAQ、真實成績案例及報價入口。
8. 馬來西亞頁以陪玩、雙排協作、復盤、第一視角教學、分路訓練和 5V5 配合為主要內容，避免把帳號代練作為廣告主訴求。
9. 更新網站地圖、AI 閱讀說明、結構資料及內部連結。
10. Google Ads 只準備每日 HK$50 的限期測試草稿；任何正式啟用及扣款必須待使用者醒來後確認。

## 後台失敗處理

營運資料讀取分為載入、可用、儲存中及錯誤四個狀態。錯誤時顯示原因類別、重新載入按鈕及價格管理返回按鈕。若沒有持久化儲存，仍可查看預設空資料，但修改按鈕必須禁用並顯示警告。

## Google 報表整合

伺服器提供一個僅管理員可讀的報表摘要入口。它以設定驅動：

- GA4：訪客、工作階段、平均互動時間、來源、HOK 頁面及重要事件。
- Search Console：曝光、點擊、CTR、平均排名，以及 HOK 頁面／查詢。

正式查詢只在伺服器端進行。前端永遠不接觸 Google 私密憑證。未設定時返回 `configured: false`，後台正常呈現而非報錯。

## 私隱與資料最小化

來源識別只在顧客同意分析 Cookie 後啟用。保存渠道、著陸路徑、來源網域、UTM 代碼及時間，不保存完整查詢字串、廣告點擊 ID 或顧客輸入。站內對話仍按現有同意與敏感資料過濾規則處理。

## 驗收標準

- 營運 API 失敗時不再空白或永遠載入。
- 每個來源渠道、`utm_content` 及 HOK 國家映射都有自動測試。
- 相同顧客查詢能在後台看到第一及最後來源，但不泄漏敏感內容。
- Google 未連接時後台有誠實提示；連接時只顯示真實回傳數據。
- 三個馬來西亞頁無 JavaScript 也有可讀內容，可被網站地圖及爬蟲找到。
- 原有 230 項測試、Lint、Production Build 仍通過。
