# Aurora 報價地區與平台欄位設計

日期：2026-08-03

## 目標

在不改動價格、服務種類或視覺風格的前提下，讓報價資料足以分辨不同伺服器、裝置平台與戰力地區，並在手動報價、Aurora 客服、聯絡摘要及營運後台使用同一份資料。

## 中央選項

- HOK／王者榮耀國際服：新增必填的「遊戲地區／伺服器大區」，所有五項服務均顯示。
  - 美洲（北美、南美及巴西）
  - 歐洲（西歐、東歐及土耳其）
  - 中東及非洲
  - 太平洋（南亞、南韓、日本及澳洲）
  - 東南亞
  - 香港／澳門／台灣
- 王者榮耀國服：新增必填的「手機系統」，所有五項服務均顯示。
  - iOS
  - Android
- 傳說對決：只在「英雄戰力標」服務新增必填的「戰力地區」。
  - 香港
  - 台灣
  - 澳門

上述選項全部存放於中央遊戲配置，使用穩定 ID 與繁體中文、英文、簡體中文顯示名稱。HOK 的六區是官方電競地區分類，用作客戶可理解的廣域選擇，欄位名稱不冒充遊戲內的精確伺服器名稱。

## 聯動與驗證

- 切換遊戲時清空三個新增欄位，避免上一款遊戲的選項殘留。
- 切換服務時，只有傳說對決戰力地區需要依服務清空；HOK 國際服大區與王者國服手機系統保留，因為它們適用於該遊戲的所有服務。
- 必填欄位未選、選項不屬於該遊戲或客戶提交偽造值時，報價不會完成。
- 新欄位只補足訂單資料，不參與價格計算，也不改變目前自動報價／人工確認規則。

## 顯示與資料流

- 手動報價表：在遊戲與服務選擇之後顯示對應欄位。
- 報價結果、WhatsApp 與 LINE：顯示已選的大區、系統或戰力地區。
- Aurora 客服：從同一中央配置讀取合法選項；資料不足時每次只追問一項。
- 查詢及訂單記錄：保存新增欄位，後台詳情能看到，敏感資料過濾與現有同意流程保持不變。

## 不在本次範圍

- 不改價格、匯率、折扣或服務清單。
- 不重新設計頁面。
- 不把 HOK 大區細分成遊戲內尚未核實的伺服器名稱。
- Google Analytics／Search Console 完整數據串接另立方案；沒有管理員授權時不得展示虛構流量。
